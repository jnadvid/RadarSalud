Cómo empezar

  1. radarsalud init-db — crea la base y siembra el catálogo de fuentes.
  2. radarsalud ingest-all — intenta ingerir datos reales abiertos.
  3. radarsalud import-csv fichero.csv — importa datos reales agregados.
  4. radarsalud analyze --mode real — detecta anomalías reales.
  5. Pulsa Simulación para probar el sistema con brotes ficticios.
